Ce que nous ne faisons pas

  • Pas de publicité, pas de revente de données.
  • Pas de compte nécessaire pour utiliser le tableau.
  • Pas de photo de personne dans la bibliothèque partagée : elles restent privées sur votre appareil.

Services extérieurs

  • ARASAAC fournit les images des pictogrammes de base.
  • Google Fonts fournit les polices du site.
  • Supabase héberge les comptes et la bibliothèque partagée.
  • La voix des pictos de base est produite par la synthèse vocale de votre navigateur.

Vos droits

Vous pouvez demander à consulter ou supprimer votre compte et les pictos que vous avez partagés. Écrivez-nous. Pour effacer les données gardées sur l'appareil, supprimez vos pictos dans l'espace parent ou effacez les données du site dans les réglages du navigateur.
